# Cópia básica do VLibras · Mente Leve

Código-fonte do player: [spbgovbr-vlibras/vlibras-player-webjs](https://github.com/spbgovbr-vlibras/vlibras-player-webjs)  
Licença: GNU LGPL v3 (`LICENSE-LGPLv3.txt`)

O player 3D original usa Unity WebGL + dicionário no servidor do governo  
(`dicionario2-dth.vlibras.gov.br`). Esta pasta traz:

- `src/` — arquivos JS oficiais do player (cópia)
- `widget-mente-leve.js` — janela no visual do VLibras, avatar chamado **Mente Leve**
- Widget oficial `vlibras.gov.br` para a sinalização 3D de verdade

Não é o suíte completo (API + Unity + dicionário). É a cópia básica que um site estático consegue rodar.
