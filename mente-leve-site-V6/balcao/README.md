# Mente Leve · Balcão

Painel da farmácia (demo). Estoque fica no navegador (localStorage).

## Subir no Vercel

1. Crie um repositório com esta pasta na raiz (index.html na raiz).
2. vercel.com → Add New → Project → Import.
3. Framework: Other. Build: vazio. Output: `.`
4. Deploy.

Ou no terminal:

```
npm i -g vercel
cd mente-leve-farmacia
vercel
```
