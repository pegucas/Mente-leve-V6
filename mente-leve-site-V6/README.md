# Mente Leve · Integrado

Projeto unificado a partir dos três arquivos:

- Site completo (páginas do app paciente + VLibras)
- Painel da farmácia / Balcão
- Seleção de entrada (Radar / gate)

## Como usar

- Abra `index.html` — tela de seleção principal.
  - **Sou paciente** → vai para `principal.html` (app do usuário).
  - **Sou a farmácia** → vai para `balcao/index.html` (painel de estoque / balcão).
  - **Ver para a Eurofarma** → página de pitch do EuroCuida.

- O login original continua em `login.html`.
- Todas as páginas do site original foram mantidas.
- VLibras incluído nas páginas principais.

Linguagem e estrutura originais preservadas. Apenas integração e leve melhoria visual na tela de seleção.
